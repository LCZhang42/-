# 寿数回战

HTML5 Canvas 单人／本地双人反应游戏原型；联机实验使用轻量 Colyseus 服务端。

当前版本 **v0.19.0 / 联机阶段 N3** 已将测试房间切换为服务器权威完整战斗。客户端只发送方向和按键输入；服务器按 60Hz 固定步长裁定移动、锁定、冲刺、寿来、牛来、伤害与攻守交换，并同步冷却和战斗事件。客户端继续预测本地移动、插值远端移动，并对服务器事件去重。N0 的确定性 `shared/SimulationCore`、本地双人、AI、A4～A6 美术与自定义角色流程保持可用。

## 当前进度

阶段 0～8（首项）已包含：

- 1280×720 固定逻辑分辨率与响应式 16:9 显示。
- 固定时间步长游戏循环。
- 同键盘双人输入与左右 Shift 独立检测。
- Esc 暂停、页面失焦自动暂停。
- F3 调试面板。
- 两名几何小人和基础 HUD。
- 双人八方向移动和对角线速度归一化。
- 冲刺、1.8 秒冷却以及短暂无锁定状态。
- 场地边界、玩家互相推挤和电线杆碰撞。
- 玩家之间的视线遮挡查询。
- R 键重置位置和冷却。
- 每局随机决定先攻；攻方按住自己的“寿”键展开有限转速的追踪锥。
- P2 可以变向、冲刺或绕柱打断锁定。
- 有效锁定约 0.75 秒完成；中断以 1.5 倍速度衰减，提前松键硬直 0.65 秒。
- 锁定进度环、目标框、调试射线和逐渐升高的合成提示音。
- 75 秒计时、每人 60 年寿命和随机先攻。
- “寿来”出招、0.42 秒回应窗口、抢答、答错与超时判定。
- 普通“寿回”反弹 6 年，完美回应反弹 9 年并交换攻守。
- 伤害恢复、安全时间、合成音效、停帧、震屏、寿字轨迹与胜负结算。
- 牛气通过锁定、完美回寿和成功诱骗积累，并以随机阈值生成单枚牛符。
- 攻方有牛符时可按“牛”键发动带低沉前摇的“牛来”，守方需用“牛”键回应“妈妈”。
- “神牛反撞”造成 5 年伤害并交换攻守；错喊会触发牛头眩晕或认亲硬直。
- B 键切换双方无限牛符测试模式。

当前版本已经包含“寿来／寿回”和“牛来／妈妈”两套心理战循环，以及阶段 5 的程序化抽象美术与打击感。

阶段 5 新增：

- 小区广场程序化背景、攻守两套视觉语言和带表情的几何小人。
- 大头、眼球追踪、开口喊话、弹簧四肢、拖鞋动作和冲刺残影。
- 命中墨迹、冲击线、颜色扫屏、镜头推拉和“攻守逆转”演出。
- 固定容量特效对象池，避免战斗过程中频繁创建粒子对象。
- 按 `V` 切换低配特效；低配模式仍保留字幕、伤害和换边提示。

阶段 6 新增：

- 首次进入自动显示五步短教学，按 `T` 可随时重看。
- 按 `O` 打开设置，可选择宽松、标准或高手反应窗口。
- 总音量、音效和中文口令播报分别控制；无系统中文语音时继续使用合成提示音。
- 可关闭字幕、命中闪光，或减弱震屏与粒子。
- 攻守身份同时使用 `▲` 和 `○` 图形标识，不只依赖颜色。
- 电线杆遮挡时显示红色断线、叉号和“视线受阻”原因。
- 本局记录锁定次数、回应成功率和双方攻方持有时间。

阶段 7 新增：

- 带版本号、键位速览和兼容性结果的开始菜单；页面加载完成前不会误开局。
- 完整暂停菜单，可继续、重开、进入设置、切换全屏或返回标题。
- 按 `X` 切换全屏；刷新或窗口失焦时始终回到安全的暂停状态。
- 缺失 Canvas、动画计时等关键能力时显示可读错误；音频、语音或全屏不可用时降级运行。
- `npm run build` 生成完整静态发布包 `dist/`，包含版本信息、联机测试页、浏览器 SDK 和 404 回退页。
- 调试面板默认关闭，正式游玩时按 `F3` 临时打开。

阶段 8 单人模式新增：

- 标题页可选择“单人 vs AI”或保留原来的“本地双人”。
- AI 固定控制青寿，能够进攻锁定、主动使用牛符、走位绕障碍、冲刺躲锁和辨认两种口令。
- AI 有新手、普通、高手三档；反应时机会波动，并可能答错或漏答，不读取玩家输入作弊。
- 单人模式有独立四步教学，P2 面板会明确显示“AI 自动控制”。

美术扩展 A0 新增：

- P1 使用原创“遛弯大爷”铁丝布偶风格；P2 暂时保留旧几何小人，方便直接对比可读性。
- 大爷拥有 6 种随战斗状态自动切换的表情：麻木、用力、震惊、喊话、看淡生死和五官错位。
- 按 `P` 循环测试“门口放空／小区监察／铁丝发癫”3 个基础 Pose。
- 按 `M` 在新布偶角色和旧几何角色之间切换；按 `F3` 可查看骨骼关节点和统一碰撞体。

美术扩展 A1 新增：

- 完成遛弯大爷、保温杯大叔、广场舞大妈、菜市场大姐和躺平青年五名原创老鼠干角色。
- 两名玩家共用同一个骨骼、表情和战斗动画渲染器；外观差异由 `CharacterDefinition` 数据驱动。
- 按 `C` 轮换 P1 角色，按 `N` 轮换 P2／AI 角色，按 `P` 轮换 P1 的基础 Pose。
- 启动时只预加载当前两名角色；其余预览图在第一次切换到该角色时加载。
- 高清生成源位于 `art-source/characters/`，网页仅加载 256×384 轻量预览图。

美术扩展 A2 新增：

- 单人和本地双人模式都会先进入正式选角页，展示五名角色的完整立绘、简介、表情预览和默认 Pose。
- 单人模式只需选择 P1，AI 自动从其余角色中选择；本地双人按 P1、P2 顺序交接选择。
- 允许本地双方选择同一角色，战斗中仍使用 P1 红橙、P2 青蓝描边以及编号和攻守符号区分。
- 浏览器会分别记住单人和本地模式最后一次阵容；角色选择不改变任何战斗数值。

美术扩展 A3 新增：

- 选角后进入 Pose 编辑器，可直接拖动躯干、肩、肘、胯和膝关节；活动范围会自动限制在安全角度。
- 键盘用户可选择关节后用方向键微调，按住 `Shift` 进行更小幅度调整。
- 提供“门口放空／小区监察／铁丝发癫”三套预设，以及镜像、重置、随机和跳过编辑。
- 每名角色拥有三个浏览器本地 Pose 槽位；覆盖和删除都需要二次确认。
- 自定义 Pose 只影响绘制，不参与碰撞、锁定和遮挡；进入战斗、暂停与重开后保持不变。

本地 MVP 稳定与验收阶段新增：

- 规则层连续推进 20 局，覆盖寿来、牛来、成功回应、超时、伤害、换边和安全时间，并持续检查状态、计时、寿命和攻守身份不变量。
- 浏览器自动验收覆盖 A5 导入、WebP 重编码、IndexedDB 刷新恢复与彻底删除，以及 A6 权利声明、生成分享码、读取预览、未配置和离线降级。
- 浏览器连续完成 20 次结算与重开，检查结算 Pose、攻方身份、演出释放和未捕获错误。
- 修复 A6 控件未传入 `Game` 导致页面无法启动，以及原生 `fetch` receiver 未绑定导致分享请求报 `Illegal invocation`。
- `npm test` 运行规则与稳定性回归；`npm run test:browser` 运行本机 Edge/Chrome 浏览器验收。

联机阶段 N0 新增：

- `shared/SimulationCore.js` 统一推进移动、碰撞、锁定、寿来、牛来、回应、伤害和攻守交换，只接收输入、固定步长与种子随机。
- `shared/SeededRandom.js` 提供可重置的确定性随机源；`CombatSystem` 不再允许隐式使用 `Math.random`。
- `shared/BalanceConfig.js` 集中保存客户端与未来服务器共用的移动、场地、锁定和战斗数值。
- 浏览器 `Game` 已改为调用共享核心；Canvas、DOM、音频、HUD、AI 决策和输入采集仍留在客户端层。
- 20 局稳定性测试已迁移到完整共享核心路径；另有 1,800 tick 确定性重放和无 DOM／Canvas／真实时钟依赖检查。

联机阶段 N1 新增：

- Colyseus BattleRoom 最多容纳两人，分配 P1／P2 座位并同步两个圆形角色的位置。
- network-test.html 可在两个标签中连接同一个本地服务器，并用 WASD 或方向键移动自己的圆。
- 客户端离开会移除对应状态；最后一人离开后房间自动释放，新房不会继承旧玩家。
- npm run test:network 会执行 SDK 双客户端与真实 Edge 双页面共 18 项验收。
- N1 只验证连接和基础状态同步；权威输入、预测、校正与插值仍属于 N2。

联机阶段 N2 新增：

- 客户端通过 Colyseus 输入通道只发送序号和方向轴，不再发送坐标或速度。
- 服务器以 60Hz 固定步长应用共享 NetworkMovement，统一限制速度、场地边界、电线杆和玩家碰撞。
- 输入轴在服务端限制到 -1～1；未声明的坐标和 speed 字段不会进入输入协议。
- 本地玩家使用回滚重放与平滑校正，远端玩家在 100ms 缓冲中插值。
- 测试页显示 sent／acked／pending、RTT 和校正误差，并提供延迟、抖动与上行丢包模拟。
- npm run test:network 在 100ms RTT 下执行 SDK 与真实 Edge 双页面共 26 项验收。

联机阶段 N3 新增：

- `BattleRoom` 复用 `SimulationCore`，由服务器权威推进锁定、冲刺、寿来、牛来、伤害和攻守交换。
- 双端同步锁定进度、视线、寿命、牛气、牛符、冷却、战斗状态与攻守身份。
- 服务器为口令、回应窗口、结算与换边发布单调事件编号；客户端只播放首次收到的事件。
- 输入协议不接受坐标、伤害、判定等级或客户端计时结果；伪造 `perfect` 字段不会影响权威裁定。
- `npm run test:network` 在 100ms RTT 下执行完整寿来／牛来流程、状态一致性与事件去重共 40 项验收。

## 启动

推荐 Node.js 22 或更高版本。首次拉取代码后安装依赖：

```powershell
npm install
```

启动本地游戏页面：

```powershell
npm run dev
```

然后访问 <http://127.0.0.1:4173>。

联机 N3 需要另开一个终端启动服务器：

```powershell
npm run server:dev
```

随后在两个标签打开 <http://127.0.0.1:4173/network-test.html> 并点击“加入测试房间”。项目脚本在当前开发机上会自动找到随 Codex 提供的 Node 24；其他电脑请直接安装 Node.js 22+，或设置 NODE22_BIN。
